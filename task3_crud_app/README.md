# Task 3: Console CRUD Application

A Java console app to manage a list of tasks (Create, Read, Update, Delete) using an `ArrayList`.

## Features
- `Task` class with id, title and status
- Add, view, update and delete tasks
- Input validation (empty title, invalid ID, invalid menu choice)

## How to run
```
javac TaskManager.java
java TaskManager
```

## Sample test scenarios
1. Add 3 tasks, then view them
2. Update a task title and mark it Done
3. Delete a task and view again
4. Try updating or deleting an ID that does not exist
5. Enter an invalid menu choice
