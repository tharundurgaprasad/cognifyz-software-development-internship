# Task 4: Temperature Converter

A Java console program that converts temperatures between Celsius and Fahrenheit.

## Features
- User chooses the conversion direction
- Handles invalid input
- Can convert multiple values in one run

## How to run
```
javac TempConverter.java
java TempConverter
```

## Test values
| Input | Output |
|-------|--------|
| 0 C | 32.00 F |
| 100 C | 212.00 F |
| 32 F | 0.00 C |
| -40 C | -40.00 F |
| abc | Invalid number message |
